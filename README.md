CodeAlpha Basic Chatbot

========================



Project Description

\-------------------



A simple rule-based chatbot created using Python. It responds to user messages using predefined replies.



Features

\--------



\- Responds to greetings such as hello, hi, and hey.

\- Answers the question "How are you?"

\- Introduces itself.

\- Displays help instructions.

\- Exits when the user types bye, goodbye, or exit.

\- Handles unknown messages.



Technologies Used

\-----------------



\- Python

\- Functions

\- While loops

\- If-elif-else statements

\- User input and output



How to Run

\----------



1\. Install Python.

2\. Open the project folder in Command Prompt or PowerShell.

3\. Run `python main.py`.

4\. Type messages to interact with the chatbot.
